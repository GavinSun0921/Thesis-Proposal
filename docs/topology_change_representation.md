# 第三项研究工作设定：结构约束关系变化下的动态场景表征维护

**2026-11-01 当前口径。** 第三项研究结构约束关系改变前后的场景表征维护：关系有效时利用跨部件观测共同构建运动表征；关系改变后调整或解除失效约束，分别维护后续运动，同时保留仍有效的历史和稳定区域信息。材料断裂及新生表面属于研究范围，但只是关系改变的一类情况。研究目标不是行为识别、事件重建或未来事件预测。课题按基础研究组织，在公开可获取数据上进行比较、消融与指标验证；数据、标注与参考不足时收窄结论，不引入实采、实体平台或定制场景建设。具体边界以[写作约定](proposal_content_plan.md)和最新正文为准，下文注明日期的旧讨论用于追溯。

## 已确认的中心问题

第一项研究“离散观测如何约束连续运动”，第二项研究“连续运动如何支撑空间结构的一致恢复”，第三项进一步研究“结构约束关系改变后如何持续维护运动与场景信息”。三项依次完善同一个场景表征，第四项利用所得表征建立动作响应模型。

第三项以结构约束关系变化下的动态场景表征维护为中心任务。关系可以描述部件装配约束，也可以描述材料连续性；不同关系具有不同的相对运动约束及有效范围。研究目标是关系有效时利用跨部件观测共同约束运动，在关系改变后调整信息共享和运动约束，并继续维护各区域表征及仍有效的历史。事件或行为识别不是目标，关系状态只作为更新场景表示的依据。

瓶盖等装配部件在关系有效时，其观测可按对应约束共同支持运动表征；关系解除后，应分别维护部件运动，不能把先前共享的约束无限延续。切割、撕裂还会破坏材料连续性并产生新表面，因此需要额外维护形成后的表面信息；装配关系改变本身不要求出现新表面。

## 关系类型与观测变化

本项的结构约束关系包括部件装配关系和材料连续性。前者改变时可以只调整部件间的运动约束；后者被破坏时可能同时发生拓扑变化及新生边界。文献中的“拓扑变化”常指表面集合或表示空间变化，比较方法时需核对其是否涉及结构关系状态和运动信息维护。

| 情形 | 需要辨别的事实 | 在本课题中的位置 |
| --- | --- | --- |
| 物体旋转，首次看到背面 | 表面已经存在，可见性改变 | 第二项的空间组织和信息累积，第一项提供连续运动基础 |
| 打开柜门，看到内部 | 部件运动使已有表面显露，装配关系可保持 | 第二项处理已有表面与空间组织；第三项不把显露本身判为关系改变 |
| 手同杯子一起运动后松开 | 共同运动或接触改变，不自动构成持续结构约束 | 第二项中的归属及共享范围问题 |
| 旋合瓶盖被拧下 | 装配约束由受限连接转为解除，未必产生新表面 | 第三项，维护关系状态及瓶盖、瓶身后续运动 |
| 切开物体或撕裂材料 | 材料连续性被破坏，并可能产生新表面 | 第三项，同时维护关系、运动及适用的表面历史 |
| 增加高斯、点、网格面或重建图边 | 模型容量或数据结构改变 | 不能单凭这一操作确定物体发生真实结构变化 |

表面在图像中首次出现和在物理上首次形成，是两个不同事件。两项工作都可能增加表示单元，也都可能缺少直接的历史观测对应，因而不能按“是否新增高斯”或“是否找得到对应”划分研究范围。

## 为什么需要进一步研究

结构约束有效时，跨部件观测和相应的运动约束有助于累积信息。关系改变后继续使用旧约束，可能把部件的后续运动错误绑定；若把场景整体重置，又会丢失关系改变前形成的有效运动历史和未变化区域的信息。

第三项需要研究运动、几何、关系类型及约束有效范围如何随观测更新，使关系改变后的各部件能够分别维护运动表征，同时延续仍然有效的历史。其验证关注关系改变前后的表征维护质量，不把事件分类或事件时刻定位作为主要指标。刚体、关节和非刚性模型均可作为关系约束的候选工具。

已有研究可以作为实现基础及比较对象，研究价值取决于具体问题的解决程度。已核查直接相关方法的表面更新机制，真实切割、撕裂的比较过程及输入条件继续收敛，不预先认定该问题无人涉及或已有方法全部失效。

## 运动历史、关系状态与表面历史

- 关系变化前由跨部件观测共同构建的运动历史继续保留；变化后仅在关系仍有效的时间范围内使用跨部件约束，并分别维护后续运动。
- 未变化区域延续具有观测支持的有效几何与运动历史，不因局部关系改变就整体重置场景表征。
- 装配关系改变若未形成新表面，不新增表面历史。切割前，截面材料可能已存在于物体内部；切割后才成为边界，因此材料运动历史与表面存在历史分别记录。
- 首次观测时间不一定是物理形成时间。若新表面在不可见区间形成，不凭首次显露时间直接确定形成时刻；只有数据支持时才评价形成时间。

## 研究和验证的候选安排

验证围绕关系改变前后的动态表征维护展开：关系有效阶段检验跨部件运动是否得到共同观测支持；关系改变后检验分部件运动误差、失效约束残留和稳定区域历史保持。若数据直接标注关系状态，可补充关系状态指标；若不提供，则不能用行为类别或事件时刻指标替代这些表征评价。

正文引用 GauSTAR 的稳定跟踪及变化区域解绑、AT-GS 的逐帧表面恢复作为已有基础；GauSTAR 对复杂或突发变化的限制依据作者第 5 节。上述论文中出现的重建拓扑变化，不直接作为真实材料切割能力已经验证或必然失效的证据。

现有候选公开数据尚未找到同时提供逐帧结构关系状态与部件级三维运动轨迹的完整标注。按各数据源实际提供的观测和参考分别评价可测分量；关系变化的直接准确率及新生表面形成时间结论均要求相应标注，不将可见变化或自动跟踪结果当作无误差真值。

关系状态由时序观测参与更新，具体关系类型、约束范围及可用参考随数据条件确定；不单列通用变化检测器，不预测未来关系变化。第四项从当前已更新的关系状态出发研究给定动作下的后续运动。

根据可用参考，检验以下表征维护效果：

- 关系有效阶段联合运动估计与关系改变后分部件运动估计的误差变化。
- 跨部件约束是否在失效后及时解除，以及关系变化前形成的信息是否仍被不恰当地用于约束变化后的运动。
- 稳定区域的运动和几何历史是否得到延续；存在断裂参考时，再评价新生表面形成后的几何与运动表示。

比较持续使用旧约束、整体重置和局部约束更新等策略时，固定可用历史、关系提示及观测条件。若参考不支持直接评价关系状态，则将结论限于运动维护和历史保持，不据训练帧渲染改善推断关系状态已被正确识别。

## 待核查事项

- 哪些公开序列能为关系改变前后的分部件运动提供足够参考？
- 各数据源中，哪些关系状态或部件身份标签可直接用于验证？
- 如何在固定历史和观测输入后比较旧约束延续、整体重置与局部重配置？

上述缺口属于验证条件和实现细节；数据不支持的关系状态结论应收窄，不转化为事件识别或自建数据集任务。

### 2026-10-26：第三项研究层次的重新讨论

用户进一步明确：四项均可围绕已有研究广泛关注的共同问题开展，具体推进体现在方法及解决程度；这一标准适用于整个课题。四项需要共同完善同一个连续动态世界模型，阶段成果能够衔接和配合。

第三项应把目标提升到“动态场景表征正确表达拓扑演化”的层次。第一项提供连续运动，第二项恢复空间结构，第三项使所得状态进一步适应真实连接及表面集合的改变，第四项利用共同状态建模动作响应。局部表面更新、失效约束调整和新生边界纳入，是服务这一表征目标的候选机制。

本次确认名称为“拓扑自适应的动态场景表征”，科学问题为“动态场景拓扑演化的时空一致表征机制是什么？”，并同步至正文目标、研究内容、科学问题及研究框架。这里的时空一致性允许真实连接发生变化，要求稳定区域延续有效历史、变化区域获得符合其形成过程的表示。

### 2026-10-27：3.2 中的拟定技术路线

依托公开结构变化序列及其可用几何条件，按实际标注区分有无事件提示的设置。图元结合局部三角表面代理，分别维护计算邻域、物理连接及置信度；经支持的失效连接进一步修正第二项的共享门控，局部表面更新保留已确认的分离关系。材料运动、表面存在区间和观测可见区间分别记录，表面历史仅在形成后且具有观测支持时建立；只有材料关联得到支持才复用早期运动。稳定区域延续关系及历史，位置和运动仍可整体更新。事件自动推断及任意断裂预测不作为本轮路线的必达条件。当前技术路线见[技术路线源码](../latex/figures/chapters/ch03-plan/topology-change-route/diagram.svg)。
