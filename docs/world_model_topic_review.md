## 1. 建议把“动态世界模型”升为题目主体

首选题目：**非完备观测下的动态世界模型研究**。

如果开题委员会希望题目明确主要研究任务，可用：**非完备观测下动态世界模型的表征与预测方法研究**。

如果已经确定博士阶段始终围绕三维空间建模，可用：**非完备观测下的三维动态世界模型研究**。目前建议把三维几何写进研究内容，暂不把它作为题目必须满足的表示形式，以便容纳显式状态、潜在状态及两者结合的后续工作。

英文可暂用 *Dynamic World Modeling under Partial Observability*。这里是研究语境下的译法，需要在报告中给出“非完备观测”的操作性定义。

导师的意见适合落实为：**题目围绕长期研究对象组织，开题正文围绕具体科学问题和阶段性验证组织。** 题目保留方法更换与应用拓展的空间，正文仍需说明博士阶段要解决什么、怎样判断是否解决。

旧题目“面向不完全观测的动态场景时空状态表征与演化研究”并没有科学性问题，但结合现稿中“重建为核心、预测与交互为有限延伸”的安排，容易把未来工作长期约束在动态重建和运动表示上。导师这次的意见意味着：世界模型成为研究对象，状态表征与恢复成为其中的基础问题，未来预测成为正式研究内容，交互用于进一步验证模型的作用。

## 2. 关键词怎样限定范围

| 表述 | 本课题中的含义 | 对研究范围的作用 |
| --- | --- | --- |
| 非完备观测 | 有限视角、遮挡、间断采样或缺测，使当前观测不能充分确定任务相关的环境状态 | 限定信息条件，同时容纳重建、历史状态维护与预测 |
| 部分可观测 | 需要通过观测与动作历史推断当前状态，并可能仍存在多个合理解释 | 适合连接状态空间模型、预测状态和交互任务 |
| 含噪观测 | 深度误差、跟踪误差、漂移及测量不确定性 | 是重要的伴随困难，但不与信息缺失等同 |
| 动态世界模型 | 建立可持续更新的内部环境状态，并预测其随时间及交互行为的变化 | 保留几何、特征、潜在状态和不同预测机制的选择 |
| 连续时间、4D 重建、VLA、GP、Gaussian 表示 | 方法路线、任务或具体实现 | 放在研究内容与技术路线中，避免用作全论文的固定边界 |

“非完备观测”可以用作中文题目，但不应宣称它与控制理论中的“不完全可观测”严格等价：一次观测不完整，并不意味着系统无法通过一段历史被辨识。报告需要分别讨论当前不可见、历史中曾经可见和始终未见的区域。

同样，遮挡后的状态不一定能被唯一恢复。若不同隐藏状态产生相同观测，模型应维护合理估计及其不确定性，或预测任务相关的量；不能承诺从任何不完整输入恢复唯一、完整的物理世界。

本课题中“动态”主要指环境状态随时间发生变化，包括物体运动、形变与交互效应。在线吸收新观测是状态更新机制，两者需要在定义中说明。

## 3. 文献是否支持这样的题目

世界模型的具体实现已经覆盖潜在状态、视觉特征和显式几何。以下是与现有基础有关的代表性证据，并非穷尽性综述。对预印本，只据其公开描述判断研究定位，不把作者报告的性能视为已独立复现的结论。

| 代表工作 | 与本次定位有关的文献事实 | 对开题的启发 |
| --- | --- | --- |
| [PlaNet，ICML 2019](https://proceedings.mlr.press/v97/hafner19a.html) | 从图像学习潜在动力学，并在包含部分可观测性的控制任务中进行规划 | 历史状态、潜在转移与部分可观测性有成熟研究基础，不能仅靠这些概念主张创新 |
| [MoSca，CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Lei_MoSca_Dynamic_Gaussian_Fusion_from_Casual_Videos_via_4D_Motion_CVPR_2025_paper.html) | 从单目视频建立紧凑运动 scaffold，融合可渲染的动态场景 | 支撑几何与运动状态的构建；其重建定位本身不构成未来预测证据 |
| [DINO-WM，2024 年预印本](https://arxiv.org/abs/2411.04983) | 在预训练视觉 patch 特征上学习动作条件预测，用于规划；像素解码器并非核心训练的必要组件 | 世界模型可以从预测特征开始，允许发挥现有表征基础 |
| [PointWorld，CVPR 2026](https://arxiv.org/abs/2601.03782) | 从部分观测的 RGB-D 和机器人动作预测三维点流；公开论文明确讨论静止初始状态假设 | 几何与运动可以成为世界预测的直接对象；运动历史与动态初始条件是可进一步考察的具体问题 |
| [Flow Equivariant World Models，2026](https://arxiv.org/abs/2601.01075) | 让结构化记忆随自运动和外部物体运动变化；论文的局限部分说明实验主要在受控刚体场景中开展 | “看不见时仍需更新状态”已有直接相关研究；真实含噪观测与更复杂形变需要进一步比较 |
| [LiveWorld，2026](https://arxiv.org/abs/2603.07145) | 以持续的背景与动态实体状态处理视野外演化，并建立相应评测 | 非完备观测与动态演化的连接是明确研究问题；文中使用文本驱动的事件条件，不能直接等同于无额外提示的真实运动预测 |
| [FR3D，2026](https://arxiv.org/abs/2606.18250) | 从单目历史预测未来动态三维重建，区分相机运动与场景运动；论文报告了预测尺度漂移等局限 | 动态重建向未来几何预测的延伸已有先例，也提供了需要比较的基线与失败模式 |
| [3D-Belief，2026 年预印本](https://arxiv.org/abs/2605.11367) | 从部分观测维护显式三维 belief，包含多假设与连续观测更新 | 对未知区域的表示与更新需要考虑不确定性，而不只是补全一个确定场景 |
| [BridgeVLA++，2026 年预印本](https://arxiv.org/abs/2608.05042) | 在 BridgeVLA 基础上增加空间与时间记忆，验证记忆相关操作任务 | 交互方向需要比较已有记忆方法，进一步证明“预测状态”相对“记忆观测”的价值 |

另外，[PERSIST](https://arxiv.org/abs/2603.03482) 已研究持续的潜在三维状态；2026-10-05 提交的 [GeoWM 预印本](https://arxiv.org/abs/2610.07381) 则提出从几何历史直接预测指定未来时距的几何。这些进一步说明，持续状态和几何预测已经是活跃路线。

据此可以支持的判断是：**用动态世界模型统摄现有基础有文献依据；“非完备观测”“持续记忆”“三维状态”应作为问题条件与研究对象，具体贡献仍需落实到方法和可检验假设。** 单篇论文的局限只说明一个可调查的切口，不证明整个领域尚未解决该问题。

现稿提及的专项背景也有官方依据：基金委于 2026-09-18 发布了[“空间智能与世界模型”专项申请指南通告](https://www.nsfc.gov.cn/p1/3381/2824/142425.html)。公开通告只确认指南已在系统中发布，不能据此推断具体资助方向或个人博士课题必须完成的内容。

## 4. 用同一个科学问题组织重建、预测与交互

建议的核心科学问题：

> 在有限视角、遮挡与间断观测条件下，如何构建并持续更新包含几何与运动信息的世界状态，预测不可见时段及未来时刻的状态变化，并利用新观测修正预测，使其支持可靠的环境理解与交互？

本课题可以把动态世界模型定义为三个相互联系的功能：观测更新、状态演化、预测读出。它们可以先在不同任务中形成方法贡献，再研究共同接口或联合约束，不必一开始承诺一个同时完成所有任务的统一网络。

对部分可观测交互，可用如下概念框架表示：

\[
h_t=(o_{1:t},a_{1:t-1}),\qquad
b_t\approx p(s_t\mid h_t),
\]

\[
b_t^- = \mathcal{T}_\theta(b_{t-1}^+,a_{t-1},\Delta t),\qquad
b_t^+ = \mathcal{U}_\phi(b_t^-,o_t),
\]

\[
\hat y_{t+\Delta}=\mathcal{D}_\psi\!\left(
\mathcal{T}^{(\Delta)}_\theta(b_t^+,a_{t:t+\Delta-1})\right).
\]

其中 \(s_t\) 是不可直接完整获取的环境状态，\(b_t\) 是模型维护的估计或 belief；上式不要求实现精确贝叶斯后验。\(y\) 可以是三维位置、点流、占据、深度或视觉特征。离散动作序列的写法适用于离散时间；连续时间扩展需要定义对应的控制信号。

纯观察视频中没有已知的机器人动作，可先研究时间条件的演化预测；这表示未显式输入交互控制，不表示外界没有作用力或未观测扰动。几何与运动表示可作为当前主要基础，潜在状态则承担历史信息、任务相关变量或难以显式辨识的因素。

### 三项研究内容

| 研究内容 | 对应问题 | 当前基础与后续增量 |
| --- | --- | --- |
| 一：非完备观测下的世界状态表征与更新 | 如何融合跨时刻信息，区分已知与未知，在新观测到来时保持几何和身份一致？ | Pomelo4D 的几何与运动状态；逐步研究可见性、不确定性及持续更新 |
| 二：观测缺失条件下的状态演化与预测 | 如何利用运动历史推演不可见区域，并控制多步预测误差，处理重新观测后的修正？ | 连续运动建模基础；新增只使用过去观测的未来预测与滚动评测 |
| 三：动作条件的世界预测与交互验证 | 状态是否能够预测不同动作的结果，并帮助部分可观测任务中的行为选择？ | BridgeVLA-Sequence 的预测状态探索；新增动作条件预测证据与记忆基线比较 |

三项内容围绕同一状态组织：先形成可更新的表征，再研究缺少观测时的演化，最后验证动作条件预测的用途。连续时间、GP、scaffold、latent memory 或新的架构都可以作为实现路线变化，科学问题保持连续。

## 5. 现有工作能支撑到哪里

以下依据 2026-09-26 草案，表示当时记录的工作基础，不能当作 2026-10-08 已重新核实的实验状态。

| 工作 | 可作为的基础 | 开题中仍需区分的证据 |
| --- | --- | --- |
| Pomelo4D | 含噪观测融合、显式几何与运动状态、连续时间查询 | 运动改进是否迁移到渲染；中间时刻验证；是否具备仅凭历史观测预测未来的能力 |
| BridgeVLA-Sequence | 持续潜在状态、动作条件转移、观测更新及 prior-observation prediction | 预测损失为零的匹配对照；多训练种子；普通记忆与预测状态的区分；多步预测及空间 grounding |

因此，两项工作可以写为“动态世界模型的不同功能基础”。Pomelo4D 支撑世界状态如何从观测中建立，BridgeVLA-Sequence 支撑状态如何在交互中维护并接受预测约束。它们目前是否形成同一个完整世界模型，要由新增接口与实验说明。

现稿把“预测与交互”作为较弱的第三项延伸。题目改为世界模型后，建议把**未来预测正式提升为第二项核心内容**；交互可以作为第三项的代表性验证，不需要同时铺开完整 VLA、强化学习与通用规划。

## 6. 可以优先调查的具体切口

结合现有基础，我更倾向先调查：**含噪、间断观测下，几何与运动共同约束的持续状态，能否改善视野外演化与未来预测？** 这是待验证的研究假设，而非已经确认的创新点。

| 候选切口 | 为什么与现有工作连接紧密 | 需要进一步证明的差异 |
| --- | --- | --- |
| 动态初始条件与间断观测下的三维预测 | 现有连续运动建模可以提供速度、轨迹和结构信息；PointWorld 明确说明了初始静止假设 | 相对历史特征预测与几何预测方法，何种运动信息带来收益，以及是否能在真实噪声下成立 |
| 遮挡期间演化与重新观测后的状态修正 | 同时连接 Pomelo 的观测可靠性问题和 Bridge 的状态更新问题 | 相对 FloWM、LiveWorld 等，是否改善未知运动、形变、测量误差或预测校准，而不只是重复保存历史 |
| 几何约束的潜在预测状态 | 为交互状态提供可检查的空间输出，可比较表征与控制之间的联系 | 几何约束是否提升未来状态预测和遮挡相关任务，普通记忆增强是否已能得到同等收益 |

一个直观的评测场景是：物体正在运动，随后被遮挡，模型依据过去的信息继续预测；物体重新出现时，检查位置、身份与预测置信度，并用观测修正内部状态。它同时覆盖“非完备观测”和“动态世界模型”，也允许从受控几何预测逐渐走向交互。

静态“曾经见过就记住”与动态“离开视野后仍继续变化”需要分别评测。始终未见的区域还存在更强歧义，适合另行评价多假设或不确定性，不宜与曾可见区域的状态跟踪混为一个指标。

## 7. 必须写清的评测边界

| 验证设置 | 模型可用的信息 | 可以支持的结论 |
| --- | --- | --- |
| 动态重建与新视角渲染 | 整段观测视频，可包含目标时刻前后的信息 | 已观测时间范围内的几何、运动与视角一致性 |
| 中间时刻插值 | 缺测时刻之前和之后的观测 | 连续表示与时间插值能力 |
| 在线状态估计 | 截至当前时刻的观测与已发生的动作 | 历史融合、当前状态维护与观测更新能力 |
| 未来状态预测 | 截至截断时刻的观测，以及明确提供的外生条件 | 未见未来时刻的预测与多步稳定性 |
| 动作条件预测及交互 | 历史观测与候选动作序列 | 动作结果预测与下游使用价值；更强因果主张还需干预证据 |

世界模型题目至少需要与所声称能力相匹配的未来预测验证。中间时间渲染有价值，但若使用未来观测进行拟合，就不能用它替代仅从过去预测未来的证据。

未来预测协议需检查整个输入构建流程，包括深度、跟踪、相机估计和状态初始化是否使用了截断后的帧。未来相机轨迹若作为已知控制条件提供，应明确标注；若也需要模型预测，应单独评价。未来帧用于构建测试标注可以成立，但不能进入预测输入。

建议最先形成三组证据：

1. **状态构建证据**：补齐当前草案记录的运动到渲染迁移及时间插值验证，并评价观测覆盖、噪声与遮挡的影响。
2. **预测证据**：在受控动态场景中设置历史截断、不同遮挡时长和缺测间隔，比较保持最后状态、简单运动外推、历史特征预测和拟研究的结构化状态方法。重点评价未来三维误差、身份保持、多步漂移及重观测修正；若输出不确定性，再评价其校准。
3. **交互证据**：在代表性的部分可观测操作任务中，匹配模型规模和训练条件，比较无记忆、普通记忆、动作条件预测状态，以及预测损失为零的版本，同时报告预测质量和任务表现。

如果主张跨场景泛化，还应增加场景分离的训练与测试，区分逐场景拟合和可迁移预测。预测损失下降、单次控制成功率提高或单步特征拟合，各自都只能支撑相应的有限结论。

## 8. 原开题草案的具体调整

建议保留原稿的问题基础，但做以下结构调整：

- 把“World Model 仅作为长期落点”改为动态世界模型的工作定义、研究对象和阶段性目标。
- 把“只研究动态场景时空状态”展开为“观测更新—状态演化—预测读出”，保留几何与运动这一当前优势。
- 把未来预测从附属应用提升为核心内容，明确与重建、插值的区别。
- 把“连续时间”从全论文范围约束移到技术路线，允许后续方法变化。
