# 当前写作约定与研究边界

更新：2026-10-30。暂定题目：**连续动态世界模型构建方法研究**。

本文件维护当前口径。2026-10-26—29 的四问安排、应用案例、操作验证和图件预览属于历史讨论，现行正文及本轮用户明确的基础研究定位优先；当前表述以本约定和最新正文为准。

## 研究定位及验证边界

课题研究有限时序观测支持的连续动态场景表征，以及表征如何约束给定动作下的演化预测。研究中心是观测、运动、结构、不确定性和预测误差之间的机制与成立条件。

- 例子和图中轨迹、立方体及切分过程用于贯通概念，不据此指定实际研究对象或新增应用任务。
- 验证以公开可获取数据为基础，采用代表方法比较、关键机制消融、困难条件及误差分析。
- 保留标准学术指标，按各基准协议设置评价阈值；不预设“达到某精度”“提升某比例”等性能目标。
- 不安排实体试件、实采标注、机械臂实验、定制应用场景或自建数据集。数据覆盖不足时，调整指标或收窄结论范围。
- 算法评测中改变采样、遮挡或输入误差属于公开数据上的分析设置，与建设新的应用实验不同。

## 表征、信息与方法边界

共同表征为 $S(t)=(\mathcal G(t),\mathcal C(t),\mathcal M(t),\mathcal Z(t),\mathcal E(t))$，依次对应几何、外观、连续运动、对象或部件归属及物理连接刻画的拓扑结构。置信度与历史有效范围作为辅助信息；交互历史补充瞬时几何未充分揭示的响应因素。

- 第一项处理区间内连续恢复；前三项的重建可利用给定区间观测。动作预测起点仅由截至 $t_0$ 的观测与动作历史构建，未来记录用于监督或评价，新观测到达后进入下一起点修正。
- 第二项纳入旋转或遮挡解除后首次显露的已有表面，组织空间归属与共享范围。邻近、共动、归属及物理连接分别解释。
- 第三项关注真实连接改变及边界新生。材料运动历史可在关联有效时延续，新生表面历史从形成后建立；可见性变化与表示单元新增各有含义。
- 第四项研究给定动作下的响应。初期在预测段内连接保持的条件下比较；新结构事件由后续观测支持的表征更新处理。
- 观测权重、软归属、连接支持度和表面门控针对不同对象更新，不能直接相互换算为概率。候选集保留尚不能排除的关键解释，覆盖率按经验指标报告。
- 三次样条、运动支撑、表面绑定和图动力学属于已有实现基础；贡献落在拟研究关系及经比较确认的增量。

## 数据、比较及指标

候选公开来源为 DyCheck iPhone、PointOdyssey、Nerfies-HyperNeRF、DROID、PointWorld-DROID 和 PhysTwin。各类数据按公开观测、标注及原协议分别使用，实际核查入口见[来源记录](reference_audit.md)。实例标签按其实际粒度评价，自动估计轨迹按带误差参考处理。

图像质量用 PSNR、SSIM、LPIPS；运动用相应基准 PCK 与三维轨迹误差；归属按可用标签计算 mIoU 及身份切换；几何按参考条件计算 CD、F-score。连接及形成时间结论要求相应直接参考。动作预测评价已记录动作下的分时域轨迹及几何误差。候选机制另报告经验覆盖、范围宽度及开销。

保持历史、输入、监督与预算可比。外部方法接口不同则分别报告原生结果；机制比较使用相同载体及响应框架。数据划分遵循官方协议或按完整场景、序列划分，留出信息不进入同一次求解或预测。历史窗与预测时域根据所用数据确定并记录，不沿用原案例设置的固定秒数。

## 写作与引用

- 研究主线使用“表征／表示”；物理状态、状态空间模型等术语按实际含义保留。
- 每项围绕一个中心任务展开，标题不并列多个独立工作；已有能力、适用条件和拟推进关系写清楚，避免重复综述和自我辩护式句子。
- 新增英文术语的中文译法沿用已确认约定；需要新译法时再确认。
- 第二、三部分不使用编号引文，方法名保留可追溯归属，所用文献在第一部分集中介绍，列表置于第四部分。
- 优先近期正式发表版本；较早未发表文献只有在影响重大且必要时保留，并记录理由。书目信息与来源核查维护于[引文记录](reference_audit.md)。
- 图示使用可编辑代码或矢量源，机制示意、已有论文结果和本课题成果分别说明。图表随首次实质讨论排布，保持正常字号，不以强制缩小掩盖内容问题。
- CoFuse4D 与 PS-VLA 的状态按已确认事实表述，不能把前期基础写成本课题已完成的成果。
