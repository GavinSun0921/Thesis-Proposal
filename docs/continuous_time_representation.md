# 第一项研究工作设定：连续时间场景状态构建

更新日期：2026-10-27。状态：研究内容名称及一句话科学问题已确认，方法和验证安排继续完善。

本文档记录整个博士课题中第一项研究的定位、信息条件、候选实现和验证安排，范围可以跨越开题报告的固定模板。报告正文按模板提炼所需内容；这里保留完整的研究考虑，并区分已确认方向和待讨论设定。

在暂定题目“连续动态世界模型的构建方法研究”下，本项承担模型的连续时间状态构建：由离散观测建立可查询几何、外观及运动信息的状态过程，作为后续空间组织、结构更新和动作条件演化的共同基础。时间连续性首先通过非采样时刻状态及信息累积检验，状态如何随观测修正另按可用观测条件说明。

对应正文：[2.2.1 连续时间场景状态构建及 2.3.1 关键科学问题](../latex/chapters/02-content.tex)。四项研究的总体关系见[写作约定](proposal_content_plan.md)。

## 已确认的研究定位

- 中心任务是连续时间场景状态构建，对应科学问题为“有限离散观测对连续运动恢复的约束机制是什么？”。多时刻几何信息的累积用于体现连续运动表征的作用，不另列为第二项独立任务。
- 论证按“离散建模的局限—连续建模的必要性—已有进展及尚存问题—本项研究切入点”展开。观测按离散时刻采集，并不意味着所有既有方法都采用离散模型；讨论发展阶段时限定到具体的连续运动表征方向。
- 已有研究是继续推进的基础和比较对象。研究价值来自问题的重要性、现有解决程度及能够取得的实质进展，不以“完全无人做过”为选题前提，也不因别人涉及过某个问题就排除继续研究。
- 本项为连续动态世界模型提供时间上连贯的场景状态，第二项进一步建立结构化空间组织，第三项使所得表征适应真实拓扑演化，第四项构建基于共同状态的动作响应模型。各项仍可基于已有表示开展，具体实现接口继续讨论，见[第二项工作设定](structured_spatial_representation.md)。

## 本项的关注点和衔接

本项主要研究离散观测对连续运动的约束，重点是采样条件、观测可靠性、运动复杂程度和模型表达能力之间的匹配关系。连续可查询是表征形式，非采样时刻的状态质量及多时刻信息累积才是需要验证的能力。

本项可以使用共享运动、局部刚性或稀疏支撑等空间先验。这些手段不等于已经解决第二项的对象或部件组织问题；第二项进一步研究空间归属的形成、延续及其对状态恢复的作用，包括将首次显露的已有表面纳入空间状态。第三项进一步研究物理连接和边界真实改变时的拓扑自适应表征，局部表面更新是其候选机制，见[第三项工作设定](topology_change_representation.md)。

## 信息条件和能力范围

目前以不同采样时刻的场景观测共同约束连续运动为出发点。以下区分用于避免混淆不同任务的能力，具体输入配置尚未确定。

| 任务 | 可使用的信息 | 需要说明的能力 |
| --- | --- | --- |
| 观测区间内的连续重建和时间查询 | 已获得的区间内观测，可按具体设置使用查询时刻前后的信息 | 从离散证据恢复连续状态，检验非采样时刻的表征质量 |
| 跨时刻几何信息累积 | 用于建模的多时刻观测及相应运动估计 | 将不同时间的信息联系到一致的场景状态，考察几何质量和累积误差 |
| 仅依赖历史的未来预测 | 预测时刻之前已经获得的观测 | 考察对未观测未来的预测能力，不能由区间内查询结果直接推断 |

连续时间表征本身不自动保证未来预测能力。第一项是否进一步开展未来外推，作为待讨论选择；第四项的动作条件预测另行设定动作输入、预测对象和交互任务。

单目或多目输入、相机参数是否已知、深度信息的来源、视频长度及采样方式均需后续明确。目前不将这些候选条件全部写成已经确定的研究前提。

## 已有基础和候选实现

CoFuse4D 的前期探索可用于梳理多时刻稠密对应、稀疏运动支撑及连续运动组织的实现经验。这是内部工作基础，不表述为本项拟开展研究已经完成。

从正文中移出的“稠密对应及可用几何信息”“紧凑的运动支撑结构”等保留为候选实现线索。如何组织连续运动、如何处理不同观测的可靠性、是否沿用时间概率先验，需要根据具体问题和比较实验确定。使用已有方法或先验不排除继续研究，其贡献需要体现为解决程度、方法机制或适用条件的实际推进。

## 拟检验的关系

以下是实验组织线索，不预设实验结论，也不要求一次覆盖所有情况。

- **采样条件。**考察采样间隔、观测数量及时间分布变化时，连续运动恢复和非采样时刻查询受到何种影响。
- **观测可靠性。**考察对应误差、几何误差和局部缺失如何影响运动估计，以及这些误差是否会在几何累积中放大。
- **运动复杂程度。**考察平缓、快速及局部变化的运动，分析表达能力、时间约束和观测证据之间的匹配关系。

比较时明确各方法实际使用的观测和先验条件。验证除图像重建外，应根据可获得标注选择运动对应、几何质量和跨时刻一致性等指标，避免仅凭轨迹更平滑或能够查询任意时间就认定表征质量提高。

## 待讨论的问题

- 首先选择哪类运动场景、输入配置和采样条件，能够形成规模合适且有代表性的研究对象？
- 第一项最主要的推进落在连续运动的表达机制、观测证据的利用方式，还是二者的匹配关系？需要结合现有方法的实际表现进一步收敛。
- 输出状态以何种形式提供几何、外观及运动信息，便于后续对象组织和交互模型使用？
- 是否开展未来外推；若开展，其范围和验证条件如何设置？

## 2026-10-27：3.2 中的拟定技术路线

以单目动态视频、已有相机估计和二维对应及可用深度先验为起点，采用显式图元和稀疏运动支撑，平移由三次 B 样条描述，旋转采用群约束曲线。循环误差、几何重投影和可见性形成证据权重，可靠对应链限定时间作用范围，结合有效支持和持续拟合偏差配置局部表达规模，再交替校正几何、运动和可靠性。权重尺度由已获观测校准；缺失证据显式记录。此为开题主路线，具体控制数、尺度、窗口和裁减判据须比较验证。连续位置、速度和可信程度作为后续接口，未来外推由动作模型另行承担。图 11 见[技术路线源码](../latex/figures/technical_route_time.tex)。
