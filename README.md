# 博士学位论文开题报告

暂定题目：**连续动态世界模型构建方法研究**。当前写作口径更新于 2026-10-30。

本课题以连续动态场景表征及其动作条件预测为基础研究对象，研究有限观测下运动、空间归属和有效结构的共同恢复，以及这些信息对响应预测的作用。验证依托公开可获取的数据，采用方法比较、机制消融和误差分析；概念例子与图中机制示意用于说明研究内容，不构成特定应用任务或数据采集承诺。

## 当前结构

第一部分按选题依据、研究现状和前期积累组织。研究现状保留四维动态场景重建、面向交互的世界模型和具身操作动作学习三个专题，分别配数量图和方法时间轴；数量是指定来源中的主题相关正式论文检索结果，口径见[统计说明](docs/literature_stats/README.md)。前期积累分别介绍 CoFuse4D 和 PS-VLA，不将其表述为已经完成本课题的四项研究。

第二部分包含整体目标、四项内容和两个科学问题。四项内容为不确定性感知的连续时间场景表征、连续运动引导的空间结构表征、物理连接变化下的连续动态场景表征，以及基于连续动态表征的动作后果预测。问题一研究不完备观测下运动与结构的可区分条件，由前三项共同支撑；问题二研究动作响应差异的表征依赖与误差传递，由第四项展开，连接变化同时联系两个问题。

第三部分依次说明共同理论、总体及四项技术路线、实施验证、可行性、研究条件、困难应对及阶段计划。3.3 按“共同实验条件—分项实施验证—科学问题与整体模型验证”组织，数据、参考标注与指标逐项对应。表征恢复与动作条件预测分别评价；连接等直接参考不足时，限定相应结论。研究条件与进度不包含实体试件、实采、机械臂操作或定制应用场景建设。

参考文献在第一部分集中引用，列表置于报告末尾并按首次引用顺序生成。文献库只保留当前正文实际引用的条目；发表状态、数据来源及历史核查见[引文核查记录](docs/reference_audit.md)。

## 编译

在项目根目录运行：

```sh
./scripts/build.sh
```

当前输出为 `latex/build/main.pdf`。编辑器主文件选择 `latex/main.tex`；学校模板、匿名开关及字体约定沿用现有配置。需要更新独立图时运行相应导出脚本，日常编译无需联网下载素材。

最新固定版本为 [20261030v2](latex/build/main-20261030v2.pdf)（2026-10-30，38 页），对应同名 Git 标签 `20261030v2`，用于回溯本版源码。历史版本 [20261028v1](latex/build/main-20261028v1.pdf) 继续保留。后续沿用 `main-YYYYMMDDvN.pdf` 及同名 Git 标签约定保存阶段版本。
