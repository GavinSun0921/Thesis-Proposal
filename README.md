# 博士学位论文开题报告

当前暂定题目：**连续动态世界模型的构建方法研究**。

截至 2026-10-26，当前稿已完成第一、第二部分的重写。第一部分包含选题依据、研究现状及已有基础，1.1 采用六段论证并配有背景插图，1.2 按四维重建、交互世界模型及具身动作学习组织。第二部分包含研究目标、四项研究内容和四个对应科学问题。第三部分保留学校模板标题、填写要求、空研究计划表及备注栏；参考文献独立置于报告末尾，作为第四部分。

课题拟研究以连续时间场景状态及其动作条件演化为核心的三维动态世界模型构建方法。“连续”以场景运动的连续时间表达为基础，状态随新增观测积累和更新；真实结构变化发生时局部调整失效联系并延续有效历史。时空一致性作为构建质量要求，通过代表性动态场景及选定具身操作检验状态和演化方法的作用。总体定位、术语界定及范围见[写作约定](docs/proposal_content_plan.md)。

1. 连续时间场景状态构建。
2. 连续运动引导的结构化空间表征。
3. 拓扑变化下的动态表面更新。
4. 连续状态驱动的动作条件演化建模。

前三项按“离散观测构建连续状态—连续运动支持空间组织—结构事件处更新局部表面”的关注点递进建立世界模型的状态基础，第四项构建基于所得状态的动作条件演化关系。四项共同服务于模型构建，并分别对应一个科学问题；各项围绕单一研究中心命名。当前内容是拟开展研究，第二项的对象、部件组织粒度及第四项具体预测接口和操作任务仍可随讨论细化。

物体旋转、部件运动或遮挡解除后首次显露的已有表面，主要由第二项纳入原有空间组织。第三项关注切割、撕裂造成的物理连接改变和边界新生；新增表示单元或缺少历史对应本身不作为真实结构变化的判据。四项的具体设定分别在上述工作文档中维护；第四项文档还记录已有交互世界模型的侧重点及本课题待检验的改进方向。

## 编译

使用 XeLaTeX + BibTeX / latexmk。在项目根目录运行：

```sh
./scripts/build.sh
```

唯一日常编译输出是 `latex/build/main.pdf`。编辑器主文件选择 `latex/main.tex`；第一、第二部分随主文件编译。参考文献独立置于报告末尾第四部分，按全文首次引用顺序编号，当前正文实际引用 39 条文献，包括 37 条正式会议或期刊论文、1 条基金委通告及 1 条近期预印本。文献库 [references.bib](latex/references.bib) 同时保留未被新稿采用的旧条目，只有实际引用条目进入文献列表；[核查记录](docs/reference_audit.md) 区分新稿依据及旧稿历史记录。

在 `main.tex` 中取消 `% \npuanonymoustrue` 一行的注释即可生成匿名版，重新注释恢复实名版。学校版式及字体选择沿用原有规则；英文回退字体按 TeX 字体文件名加载。
