# 博士学位论文开题报告

当前暂定题目：**连续动态世界模型的构建方法研究**。

截至 2026-10-28，当前稿已完成第一、第二部分的重写。第一部分包含选题依据、研究现状及已有基础，1.1 采用六段论证并配有背景插图，1.2 按四维重建、交互世界模型及具身动作学习组织，三个主题分别配有真实重建结果、三维交互预测及典型输入输出示意。第二部分包含研究目标、四项研究内容和四个对应科学问题，四项内容各配一张原创问题示意图。第三部分第一栏已完成 3.1“主要理论及研究方法”、3.2“总体技术路线及分项技术路线”和 3.3“实施方案及验证设计”初稿。3.2 配有一张总体路线图及四张分项路线图，明确主要状态接口、建模机制和信息条件；3.3 按共同条件、分项验证和整体集成组织，补充候选数据示例、评价指标表及二维和三维运动指标图解，具体序列、实验规模和参数随研究推进确定。第二栏已完成 3.4“研究计划可行性分析”、3.5“研究条件落实情况”和 3.6“可能存在的问题及解决办法”初稿；第三栏已直接填写模板研究计划表，并完成 3.7“预期创新点及成果形式”初稿，保留备注栏。参考文献独立置于报告末尾，作为第四部分。

课题拟研究以连续时间场景状态及其动作条件演化为核心的三维动态世界模型构建方法。“连续”以场景运动的连续时间表达为基础，状态随新增观测积累和更新；真实结构变化发生时局部调整失效联系并延续有效历史。时空一致性作为构建质量要求，通过代表性动态场景及选定具身操作检验状态和演化方法的作用。总体定位、术语界定及范围见[写作约定](docs/proposal_content_plan.md)。

| 研究内容 | 对应科学问题 |
| --- | --- |
| 连续时间场景状态构建 | 有限离散观测对连续运动恢复的约束机制是什么？ |

前三项按“离散观测构建连续状态—连续运动支持空间组织—表征适应真实拓扑演化”的关注点递进完善共同场景状态，第四项构建基于所得状态的动作响应模型。四项共同服务于模型构建，并分别对应一个科学问题；各项围绕单一研究中心命名。局部表面更新及失效联系调整是第三项表征目标的候选机制。当前内容是拟开展研究，第二项的对象、部件组织粒度及第四项具体预测接口和操作任务仍可随讨论细化。

物体旋转、部件运动或遮挡解除后首次显露的已有表面，主要由第二项纳入原有空间组织。第三项关注切割、撕裂造成的物理连接改变和边界新生；新增表示单元或缺少历史对应本身不作为真实结构变化的判据。四项的具体设定分别在上述工作文档中维护；第四项文档还记录已有交互世界模型的侧重点及本课题待检验的改进方向。

## 编译

使用 XeLaTeX + BibTeX / latexmk。在项目根目录运行：

```sh
./scripts/build.sh
```

日常编译输出为 `latex/build/main.pdf`，作为随源码更新的当前阅读版；同一目录下的 `aux`、`log`、`xdv`、`synctex.gz` 等中间文件由 `.gitignore` 排除。确认阶段版本时，将审定后的 `main.pdf` 复制为 `main-YYYYMMDDvN.pdf` 入库，并建立同名 `YYYYMMDDvN` Git 标签；当前固定版本为 `main-20261028v1.pdf`。改动正文后重新运行编译脚本，再提交源码及相应 PDF 即可同步远端阅读版。编辑器主文件选择 `latex/main.tex`；第一、第二部分随主文件编译。参考文献独立置于报告末尾第四部分，按全文首次引用顺序编号，当前正文实际引用 84 条资料，包括 81 条正式会议或期刊论文、1 部正式出版专著、1 条基金委通告及 1 条 2026 年预印本。文献库 [references.bib](latex/references.bib) 同时保留未被新稿采用的旧条目，只有实际引用条目进入文献列表；[核查记录](docs/reference_audit.md) 逐条列出当前引用的出版信息及核验来源，并保留旧稿历史记录。

在 `main.tex` 中取消 `% \npuanonymoustrue` 一行的注释即可生成匿名版，重新注释恢复实名版。学校版式及字体选择沿用原有规则；英文回退字体按 TeX 字体文件名加载。
